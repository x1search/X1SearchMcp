# Security Policy

## Reporting a Vulnerability

If you believe you've found a security vulnerability in this project, please report it
privately rather than opening a public issue.

- Preferred: use [GitHub Security Advisories](https://github.com/x1search/X1SearchMcp/security/advisories/new)
  for this repository, which lets you submit a private report.
- Alternatively, email **srobinson@x1.com** with details and, if possible, steps to reproduce.

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce, or a proof of concept.
- The version/commit of X1SearchMcp affected.

## What to expect

We aim to acknowledge new reports within 5 business days, and will keep you updated as we
investigate and work on a fix. Please give us reasonable time to address the issue before any
public disclosure.

## Scope

This repository contains the X1 Search MCP bridge/connector (the "Lean" flavor): the process
that exposes a local X1 Search index to Claude Desktop, Claude Code, and claude.ai over MCP.
It does not include the X1 Search desktop application or index itself, which are closed-source
and out of scope for reports made here — see https://www.x1.com/submit-a-case-x1-search/ for
those.
